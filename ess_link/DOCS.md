# ESS LINK → MQTT

Зчитує показники інвертора Sinexcel / EnSmart SolarAll із донгла ESS LINK AGN8 по локальній мережі та публікує їх у MQTT. Home Assistant створює пристрій із сутностями сам (MQTT Discovery). Додаток працює лише на читання.

## Налаштування

| Опція | Опис |
|---|---|
| `dongle` | Адреса донгла, за потреби з портом (`<dongle-ip>` або `<dongle-ip>:8888`). Обов'язкова для одного інвертора. |
| `device_name` | Назва пристрою в Home Assistant, за замовчуванням «Інвертор». Якщо інверторів кілька, дайте кожному свою. |
| `inverters` | Список, якщо інверторів кілька: у кожного `name` (назва пристрою в Home Assistant) і `dongle`. Назви й адреси мають бути різними. Можна поєднувати з `dongle`. |
| `mqtt_host` | Власний брокер, `адреса` або `адреса:порт`. Якщо порожньо, додаток бере додаток Mosquitto broker автоматично. |
| `mqtt_user`, `mqtt_password` | Облікові дані власного брокера. Порожній користувач означає підключення без автентифікації. |
| `verbose` | Докладний журнал. |

Для Mosquitto broker досить вказати `dongle`. Користувач власного брокера має мати право публікувати в `esslink/#` і `homeassistant/#`.

## Зауваження

- На один інвертор має працювати один збирач; з кількома інверторами додаток сам запускає по одному на кожен. Журнал кожного має в рядках префікс `[назва]`. Не вказуйте той самий донгл двічі.
- Порт 8888 донгла не має автентифікації: тримайте його в довіреній мережі.
- Часовий пояс інвертора має збігатися з часовим поясом Home Assistant, інакше датчик «Відхилення часу інвертора» покаже різницю.
