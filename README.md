# ESS LINK для Home Assistant

Додаток для Home Assistant OS і Supervised: показники інвертора Sinexcel / EnSmart SolarAll із донгла ESS LINK AGN8 у MQTT. Налаштування й опис: [ess_link/DOCS.md](ess_link/DOCS.md).

[![Додати репозиторій у Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fseishio%2Fess-link-addon)

1. Встановіть додаток **Mosquitto broker** і додайте інтеграцію MQTT.
2. *Налаштування → Додатки → Магазин додатків → ⋮ → Репозиторії*: додайте `https://github.com/seishio/ess-link-addon`.
3. Встановіть «ESS LINK», вкажіть адресу донгла й запустіть.
